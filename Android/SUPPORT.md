## When Reporting an Issue

Please include:
1. Your Meta Quest model (Quest 2, Quest Pro, Quest 3, or Quest 3S)
2. Horizon OS software version (Settings &rarr; System &rarr; Software Update)
3. VisionPlayer app version (e.g., 26.0.1)
4. A description of the problem and steps to reproduce
5. The video file format/codec if applicable (e.g. MKV / HEVC / AV1 / VR180)

## Common Questions & Solutions

### 1. Which devices are supported?
Meta Quest 2, Meta Quest Pro, Meta Quest 3, and Meta Quest 3S.

### 2. How do I stream from my Mac, PC, or NAS?
Enable Windows File Sharing (SMB) on your PC/Mac or NAS on your local Wi-Fi. Open VisionPlayer, navigate to the **Network** tab, select your server, and enter your share credentials.

### 3. How do I use Hand Tracking?
VisionPlayer supports Meta Quest Hand Tracking 2.0. Pinch and point to interact with panels, play/pause, seek, and adjust settings without controllers.

### 4. How do I correct 3D or VR video projection?
VisionPlayer auto-detects 3D/VR formats from filenames (`_180_sbs`, `_360_ou`, `_fisheye`). If a file is incorrectly detected, open player settings and manually select the projection (2D / VR180 / VR360) and 3D mode (SBS / Over-Under). Your setting is saved per video.
